# glenley downloads

Installers and app updates for [glenley](https://glenley.in): remote access to your Mac or
Windows PC from any browser.

Get it from **[glenley.in](https://glenley.in)**, or pick a file from the
[latest release](https://github.com/shivambisen/glenley-releases/releases/latest):

- **Windows:** `glenley-setup-windows-x86_64.exe`
- **Mac (Apple silicon):** `glenley-macos-arm64.zip`
- **Mac (Intel):** `glenley-macos-x86_64.zip`

Each file has a `.sha256` checksum beside it. The glenley app updates itself from here.

This repository only holds release files.
